# 📊 Neurofibromatosis Type 1 (NF1) Clinical Insights Dashboard

An exploratory data analysis and clinical visualization project analyzing a cohort of 296 Neurofibromatosis Type 1 (NF1) patients sourced from the **UCI Machine Learning Repository**.

---

## 🎯 Project Summary
* **Dataset Size:** 296 patient records ($N = 296$, 20 features)
* **Key Focus:** Symptom prevalence, co-occurrence patterns, diagnostic age trends, and inheritance background (Familial vs. Sporadic).
* **Interactive Dashboard: link (https://public.tableau.com/app/profile/abdennour.hicheur/viz/NeurofibromatosisType1NF1ClinicalInsightsDashboard/NeurofibromatosisType1NF1ClinicalInsightsDashboard )

---

## 📈 Key Clinical Findings
* **Ubiquitous Hallmark:** Café-au-lait spots (CLS) are present in over 91% of patients ($n = 271$).
* **Strong Co-Occurrence:** Axillary and inguinal freckling demonstrate a strong statistical co-occurrence, forming a core diagnostic cluster.
* **Inheritance Parity:** Active tumour manifestation (~14%) and overall symptom distribution show no significant difference between Familial and Sporadic cases.
* **Pediatric Concentration:** Over 60% of all diagnoses occur before age 10.
